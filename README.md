# 🏨 Meu Hotel 🏨

💻 Aplicativo desenvolvido em C#, XAML e .NET MAUI como atividade prática da disciplina de Desenvolvimento de Sistemas II.
O projeto permite calcular diárias, selecionar acomodações, informar a quantidade de hóspedes e escolher as datas de check-in e check-out.
